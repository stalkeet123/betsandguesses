# Party Challenge Deck v1

> Superseded by [Party Challenge Deck v2](party_challenge_deck_v2.md).

Production catalog generated from the authoritative seed migration.

## Final deck

| Category | Count | Betting format | Performer incentive |
|---|---:|---|---|
| Verbal | 20 | Five authored numeric ranges | More valid answers |
| Physical | 15 | Five authored numeric ranges | More reps or seconds |
| Dare | 10 | YES / NO | Complete the dare |
| Precision | 15 | First / second / third / 4–5 / fail | Succeed earlier |

## Curation decisions

- Removed disputed or geography-dependent Europe-list counting.
- Removed the one-leg hopping challenge because fatigue raises injury risk.
- Replaced key tossing with a coin-and-sturdy-mug challenge.
- Replaced the dating-profile fallback dare with one objective prompt.
- High-consequence external actions such as messaging an ex or posting publicly remain outside the base deck.
- Attempt challenges are not generic numbers: failure is explicit and the host may end the timer early.
- Prop requirements appear before performance, and the host can reroll during betting.
