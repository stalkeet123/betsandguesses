Quick help

Start with the common fixes.

Most game-night issues can be cleared without restarting the room.

I cannot join a room

Check the room code exactly as the host shows it and confirm the host still has the room open. Refresh once, enter the code again, and keep the browser tab active while joining. If the room has ended, the host will need to start a new room.

Do guests need the app or an account?

No separate guest app download is required for normal browser play. Open the web game, enter the room code, and choose a display name. A traditional email-and-password account is not required for normal guest play.

Classic and Party Poll look different — is that expected?

Yes. Classic uses a numeric guess phase followed by a betting board. Party Poll skips the numeric guess and asks the group to bet on people in the room. The round structure and scoring are intentionally different between the two modes.

The timer, chips, or table looks out of sync

Return to the game tab and keep a stable connection. If the view does not recover, refresh and rejoin the same room. The game reloads the current server state, so a refresh is usually safer than repeatedly tapping controls on a stale screen.

There is no sound in my browser

Mobile browsers usually require a tap or click before they allow game audio. Interact with the page once, then check the tab's mute state and your device volume. Keeping the game tab in the foreground also helps prevent browser audio suspension.

The page looks cramped or part of the board is missing

Rotate back to the orientation the game opened in, return browser zoom to 100%, and close any browser UI that is forcing an unusually small viewport. If the layout still looks wrong, send us the device model, browser, and a screenshot.

My purchase or premium access is missing

Make sure the device is using the Apple ID that owns the purchase, then fully close and reopen the app. If access is still missing, email support with your device model, iOS version, and app version. Never send passwords, full payment-card details, or other sensitive credentials.

Still need help?

Tell us what happened.

Include the room code, device model, browser or iOS version, app version, game mode, and the round where the issue appeared. A screenshot is useful when the problem is visual.
