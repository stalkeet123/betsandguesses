Quick help

Start with the common fixes

Most game-night issues can be cleared in under a minute.

I cannot join a room

Check that the room code is entered exactly as shown and that the host is still in the lobby. Refresh the page once, enter the code again, and keep the browser tab active while joining.

There is no sound in my browser

Browsers require a tap or click before they allow game audio. Interact with the page once, then check the tab's mute setting and your device volume.

The timer or table looks out of sync

Keep a stable connection and return to the game tab. If the display does not recover, refresh and rejoin with the same name; the current server state will be loaded again.

My purchase or premium access is missing

Email us from the address used for the App Store purchase and include your device model, iOS version, and app version. Do not send payment details or passwords.
